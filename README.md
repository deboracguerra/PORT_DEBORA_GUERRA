## 🛠️ Tecnologias Utilizadas
- **React 19** + **TypeScript**
- **Vite** (com suporte nativo a caminhos relativos para GitHub Pages)
- **Tailwind CSS v4**
- **Lucide Icons**
- **GitHub Actions** (deploy automático para GitHub Pages)

---

## 🚀 Como Executar Localmente

1. **Instalar Dependências:**
   ```bash
   npm install
   ```

2. **Iniciar Servidor de Desenvolvimento:**
   ```bash
   npm run dev
   ```
   Acesse: `http://localhost:3000`

3. **Compilar para Produção (Gerar pasta `dist/`):**
   ```bash
   npm run build
   ```

---

## 🌐 Publicação no GitHub Pages

Este repositório já inclui a action `.github/workflows/deploy.yml` pronta para publicar o site automaticamente no GitHub Pages:

1. Crie um novo repositório no seu GitHub.
2. Suba os arquivos deste projeto.
3. No GitHub, vá em **Settings > Pages > Source** e selecione **GitHub Actions**.
4. Seu portfólio estará online em `https://<seu-usuario>.github.io/<nome-do-repositorio>/`.

Consulte o arquivo `COMO_PUBLICAR_NO_GITHUB.md` para instruções detalhadas passo a passo.
