## 🌐 Como o GitHub lê e exibe este código

Este projeto foi construído no formato **HTML5 estático universal**:
- **`index.html`**: É o arquivo que o **GitHub Pages lê diretamente**. Ele contém toda a estrutura do site, o design moderno (Tailwind CSS via CDN rápida) e as traduções bilíngues (Português/Inglês) em JavaScript nativo.
- **Não precisa de compilação nem terminal**: O GitHub Pages lê o `index.html` e coloca o site no ar imediatamente! Qualquer navegador abre o site direto.
- **`.nojekyll`**: Informa ao servidor do GitHub para servir todos os arquivos estáticos sem filtros.

## 📸 Como Substituir a Imagem de Perfil

Você pode trocar a sua foto de perfil a qualquer momento sem mexer em nenhuma linha de código:

1. **Escolha sua nova foto** (formato JPG ou PNG).
2. **Renomeie o arquivo para:**
   - `profile.jpg` (ou `profile.png`)
3. **Substitua o arquivo na raiz do repositório** (na mesma pasta onde está o `index.html`).
4. **Pronto!** O site carregará sua nova foto automaticamente com enquadramento circular, efeitos de foco e alta resolução.

> 💡 *Dica no GitHub Web:* No seu repositório no GitHub, clique em **Add file** > **Upload files**, arraste o seu arquivo `profile.jpg` e clique em **Commit changes**. A foto atualiza na hora!

## 🚀 Como Publicar no GitHub Pages (Passo a Passo)

### Método Mais Rápido (3 cliques):
1. Crie um repositório no seu GitHub (exemplo: `portfolio` ou `deboracguerra.github.io`).
2. Faça o upload dos arquivos (ou descompacte o arquivo `portfolio-debora-guerra.zip` e suba os arquivos).
3. No GitHub, clique na aba **Settings** (Configurações) no topo do seu repositório.
4. No menu lateral esquerdo, clique em **Pages**.
5. Na seção **Build and deployment** > **Source**, selecione:
   - **Deploy from a branch**
   - Branch: `main` (ou `master`)
   - Pasta: `/(root)`
6. Clique no botão **Save**.
7. Aguarde cerca de 30 a 60 segundos: o GitHub exibirá o link público do seu site (ex: `https://seusuario.github.io/portfolio/`)!
